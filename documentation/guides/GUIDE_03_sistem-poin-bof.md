# GUIDE 03 — Cara Menggunakan Sistem Poin BOF

## Tujuan
Memahami dan menerapkan **sistem poin BOF RESMI** saat menilai hasil setiap match, sehingga leaderboard di website benar dan tidak ada sengketa poin.

## Prasyarat
- Memahami hasil akhir satu match: **placement** (peringkat finish 1–12) dan **jumlah kill** tiap tim.
- Sudah membuat turnamen dan tim ([GUIDE_01](GUIDE_01_membuat-turnamen.md), [GUIDE_02](GUIDE_02_menambahkan-peserta-tim.md)).

**Rumus resmi:** `Total match = poin placement + (jumlah kill × 2)`.
**Poin turnamen = jumlah poin dari seluruh match yang sudah dipublikasikan.**

## Langkah-langkah Menghitung
1. Setelah game selesai, catat **placement** setiap tim (1st–12th) dan **jumlah kill**.
2. Ambil poin placement dari tabel (1st=20, 2nd=17, 3rd=15, 4th=13, 5th=12, 6th=10, 7th=6, 8th=4, 9th=3, 10th=2, 11th=1, 12th=0).
3. Kalikan kill dengan **2**.
4. Jumlahkan keduanya = **total match**.
5. Input hasil ke website (lihat [GUIDE_04](GUIDE_04_memasukkan-hasil-pertandingan.md)), lalu **publikasikan**.
6. Poin turnamen tim bertambah otomatis dari match yang dipublikasikan.

**Contoh resmi (hafalkan untuk latihan panitia):**
- **TEAM ALPHA** finish **1st** dengan **8 kill** → 20 + (8 × 2) = 20 + 16 = **36 poin**.
- **TEAM BRAVO** finish **2nd** dengan **5 kill** → 17 + (5 × 2) = 17 + 10 = **27 poin**.
- **TEAM CHARLIE** finish **7th** dengan **3 kill** → 6 + 6 = **12 poin**.

## Aturan Tiebreaker (Poin Sama)
1. **Total poin** lebih tinggi menang.
2. Jika sama, bandingkan **placement points** (jumlah poin placement, bukan kill).
3. Jika masih sama, bandingkan **placement di game terakhir sesuai format**: BO7 → lihat game 7, BO5 → game 5, BO3 → game 3, Custom → game terakhir yang ditentukan.
4. Jika masih sama → **review manual oleh panitia** dengan bukti rekaman.

## Tips
- Cetak tabel poin ini dan tempel di meja operator saat hari-H.
- Gunakan dua panitia berbeda untuk menghitung terpisah, lalu bandingkan hasil sebelum input.
- Ingat: match **belum dipublikasikan tidak ikut dihitung** — jangan heran leaderboard berubah setelah publikasi.

## Kesalahan Umum
- Menghitung kill × 1 atau × 3 — aturan resmi selalu **× 2**.
- Menukar placement dan kill saat input (mis. 8th dianggap 8 poin — yang benar 8th = 4).
- Menghitung match uji/latihan ke poin resmi.
- Mengubah poin tanpa bukti — semua koreksi harus disertai rekaman/screenshot.
- Memutuskan tiebreaker sebelum memeriksa tiga urutan aturan di atas.
